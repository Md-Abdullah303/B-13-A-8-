### Project name : QurbaniHat – Livestock Booking Platform

---

## Purpose : 
This website is easy to use for buy Animals for Qurbani. It's a responsive web application that can use be in mobile, tablet and pc. People can saw animals like cow and goat and saw there details. And easily booking for them self.

--- 

## Key features : 
1. Easy to use for booking animal
2. You can signup, register and  login by google for saw animal details
3. You can update your profile name and Image by url
4. Easy to saw all animals
5. Responsiveness for mobile, tablet and Pc.

---

## Tools that I use: 
1. Nextjs
2. Hero Ui
3. Better auth
4. MongoDB Atlas
5. React icons
6. React Toastify
